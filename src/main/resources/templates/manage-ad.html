Cómo obtener la URL directa de una imagen
Importante: Para que los anuncios se muestren correctamente, necesita usar la URL directa de la imagen o GIF.
¿Qué es una URL directa?

Una URL directa es una dirección que apunta directamente al archivo de imagen y generalmente termina en .jpg, .png, .gif, etc.

Ejemplos de URLs directas (correctas)
  • https://ejemplo.com/imagen.jpg
  • https://ejemplo.com/carpeta/mi-gif-animado.gif
  • https://cdn.ejemplo.com/productos/123456.png
Ejemplos de URLs incorrectas
  • https://www.google.com/url?sa=i&url=https%3A%2F%2F...
  • https://www.google.com/search?q=gif+animado&tbm=isch...
  • https://ejemplo.com/pagina-con-imagen.html
Cómo obtener la URL directa:
  1. Encuentre la imagen que desea usar en Google u otro sitio
  2. Haga clic derecho sobre la imagen
  3. Seleccione "Copiar dirección de imagen" o "Copy image address"
  4. Pegue la URL en el campo de texto

Si aún tiene problemas, puede subir directamente un archivo haciendo clic en el botón de carga.
